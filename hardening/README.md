# Hardening Linux

Cette section regroupe les contrôles visant à réduire la surface d'attaque : services inutiles, permissions, comptes, configuration réseau, mises à jour, journalisation et vérifications d'audit.

## Principe

Durcir sans casser : comprendre la fonction d'un service ou d'un réglage, mesurer son utilité, appliquer le changement, puis vérifier l'effet.
