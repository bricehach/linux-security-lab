# Kali Linux & Parrot Security

Cette section documente l'utilisation de Kali Linux et Parrot Security dans des laboratoires personnels ou pédagogiques autorisés.

## Positionnement

Ces distributions sont des environnements spécialisés. L'objectif n'est pas d'accumuler des outils, mais de comprendre leur usage, leurs prérequis, leurs résultats et leurs limites.

Les travaux publiés ici resteront orientés apprentissage, audit autorisé, diagnostic et cybersécurité défensive.
